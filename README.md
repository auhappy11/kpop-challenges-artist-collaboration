# K-pop Collaboration Shorts Dataset (v16)

Positive samples for the K-pop short-form challenge collaboration study: every
YouTube Shorts dance challenge in which a main artist appears with a guest artist,
uploaded between 2022-01-01 and 2024-10-29.

File: `data/final_collab_shorts_positives_v16.csv`

| | |
|---|---|
| Rows | 6,008 directed collaboration ties (main artist → guest artist in one Short) |
| Distinct Shorts | 5,940 (66 Shorts feature 2–3 guests and appear once per guest) |
| Artists | 207 (186 main, 206 guest) |
| Distinct directed artist pairs | 4,369 |
| Songs | 597 |
| First-time / recurring | 4,521 / 1,487 |
| Used in v16 models | 5,949 (59 dropped when balancing classes 1:1) |

Feature values are identical to the positive rows of the v16 model datasets.

## Collaboration type

`collab_type` is based on **directed** pair history: a tie A → B is `recurring`
if A had already featured B in an earlier Short, otherwise `first_time`.
A → B and B → A are counted separately.

## Model features (32), by category

| Category | Features |
|---|---|
| **MS** – Music similarity | `music_similarity` |
| **OAS** – Original (main) artist song audio | `main_bpm`, `main_energy`, `main_danceability`, `main_happiness`, `main_acousticness`, `main_instrumentalness`, `main_liveness`, `main_speechiness`, `main_loudness` |
| **GAS** – Guest artist song audio | `collab_bpm`, `collab_energy`, `collab_danceability`, `collab_happiness`, `collab_acousticness`, `collab_instrumentalness`, `collab_liveness`, `collab_speechiness`, `collab_loudness` |
| **SP** – Social / relational | `same_gender`, `same_agency`, `past_engagement`, `past_engagement_raw`, `debut_date_difference`, `main_korean_member_ratio`, `collab_korean_member_ratio`, `shared_non_korean_nationality` |
| **TP** – Title-track promotion | `has_recent_title_track` |
| **P** – Popularity | `avg_past_album_sales_main`, `avg_past_album_sales_collab`, `ratio_avg_album_sales`, `temporal_shorts_count` |

`past_collab` is retained for reference but excluded from the models (it defines
`collab_type`).

## Other columns

| Column | Description |
|---|---|
| `id` | YouTube video ID of the Short |
| `main_artist_group`, `collaboration_groups` | Main artist and guest artist |
| `song_title`, `release_date` | Main artist's song featured in the challenge |
| `published_at` | Upload date of the Short |
| `main_*` / `collab_*` debut date, gender, agency, days since debut, key, duration | Artist and song metadata |
| `view_count`, `like_count`, `comment_count` | Engagement of the Short at collection time |
| `appear_on_chart`, `debut_rank_score`, `peak_rank_score`, `days_on_chart`, `days_to_enter`, `days_to_peak`, `average_rank_score_*` | Chart performance |
| `album_sales`, `days_on_chart_retail`, `max_/total_past_album_sales_*` | Album sales |
| `collaboration_occurred` | Always 1 (positive samples) |

## Notes

- Engagement counts are snapshots from the YouTube Data API and are subject to
  YouTube's API Terms of Service.
- This repository contains positive samples only. Negative samples for the v16
  models are generated by the study's sampling pipeline.
